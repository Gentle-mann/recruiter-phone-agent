# recruiter-phone-agent

Two apps live in this repository.

| Folder | What it is | Run |
|---|---|---|
| `callscreen/` | Callscreen: recruiter dashboard on Convex. Pipeline board per role, candidate profiles, role setup, public application page. Vite + React. | `cd callscreen && npm install && npm start` |
| `firstcall/` | Firstcall: Next.js hackathon scaffold with an ElevenLabs practice-session page and fixture data. | `cd firstcall && npm ci && npm run dev` |

Each folder has its own `package.json`, README, and tooling. There is no root package.
